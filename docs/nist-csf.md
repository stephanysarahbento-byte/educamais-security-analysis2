# NIST Cybersecurity Framework 2.0 — Aplicação na EducaMais

## 1. Visão geral

O NIST Cybersecurity Framework (CSF) 2.0 fornece uma estrutura para organizar e gerenciar os riscos de segurança cibernética.

O framework é composto por seis funções:

- Govern;
- Identify;
- Protect;
- Detect;
- Respond;
- Recover.

## 2. Aplicação na EducaMais

### Govern

Estabelecer políticas de segurança, responsabilidades, critérios de risco e processos de governança.

Essa função é importante porque a EducaMais não possui um processo formal de gestão de riscos.

### Identify

Identificar os ativos, sistemas, dados, usuários e riscos existentes no ambiente.

A empresa deve conhecer especialmente os sistemas relacionados a cadastro, pagamentos, autenticação e acesso aos materiais didáticos.

### Protect

Implementar medidas para reduzir a probabilidade e o impacto dos incidentes.

Entre as medidas prioritárias estão:

- MFA para contas administrativas;
- Controle de acesso baseado em funções;
- Proteção das credenciais;
- Gestão de vulnerabilidades;
- Configuração segura dos sistemas.

### Detect

Implementar mecanismos para identificar atividades suspeitas e possíveis incidentes.

Entre as medidas estão:

- Monitoramento de logs;
- Detecção de acessos suspeitos;
- Monitoramento de tentativas de autenticação;
- Alertas para comportamentos anômalos.

### Respond

Estabelecer procedimentos para responder aos incidentes identificados.

A EducaMais deve definir:

- Responsáveis pela resposta;
- Procedimentos de contenção;
- Comunicação interna;
- Registro dos incidentes;
- Análise das causas.

### Recover

Estabelecer procedimentos para recuperar os serviços após um incidente.

Entre as medidas estão:

- Backups;
- Testes de recuperação;
- Procedimentos de continuidade;
- Restauração dos serviços;
- Avaliação pós-incidente.

## 3. Justificativa

O NIST CSF é especialmente útil para a EducaMais porque permite organizar a segurança como um ciclo contínuo.

O framework conecta governança, identificação de riscos, proteção, detecção, resposta e recuperação.

Dessa forma, ele complementa a visão de gestão da ISO 27001 e ajuda a estruturar uma resposta aos incidentes já observados na empresa.

## 4. Relação com os demais frameworks

A ISO 27001 fornece a estrutura de gestão e governança.

O NIST CSF organiza as atividades de segurança em um ciclo.

Os CIS Controls fornecem ações práticas para implementação dos controles.

A OWASP complementa a abordagem com foco específico na segurança da aplicação web.
